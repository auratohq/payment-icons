# Aurato payment icons

A collection of payment-related icons maintained by [Aurato](https://aurato.io).

The collection is being prepared from Aurato's public asset library. It covers payment methods, schemes, systems, operators, PSPs, banks, markets, currencies, regulators, compliance, standards, identifiers, and card artwork.

Primary icons use a rounded-square base. Card artwork keeps its card proportions in the `cards/` directory. Category directories live at the repository root.
